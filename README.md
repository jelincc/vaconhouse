| 화면 | 경로 |
| --- | --- |
| 관리자 로그인 | `/` |
| 관리자 예약 관리 (오늘 할 일 · 보드 · 목록 · 달력) | `/admin/reservations.html` |
| 관리자 예약 상세 | `/admin/reservation.html?id=48` |

| 직원 앱 · 회사 숙박권 (가입 → 소속 확인 요청 → 예약·변경·취소) | `/app/corp.html` |
| 앱 선물 사용 내역 | `/app/gift.html` |

로그인은 시안용으로, 아이디 `jelin` · 비밀번호 `12`를 입력하면 예약 관리 화면으로 이동합니다. 화면의 예약·직원 데이터는 모두 예시입니다.

직원 앱에서 소속 확인을 요청하면 기업 관리자 화면에 요청이 뜨고, 확인·권한 부여 후 직원 앱에서 예약하면 기업 관리자 예약 내역과 본사 예약 보드에 함께 나타납니다. 시안 데이터는 브라우저에 저장되며 로그아웃하거나 직원 앱의 "시안 초기화"로 되돌릴 수 있습니다.
